# 발로 에임장 — 바인드

발로란트 **바인드 맵**을 그대로 걸어다니면서 **밴달**로 에임 연습하는 브라우저 연습장입니다.
그래픽은 최소한(면 색 + 1m 타일 무늬)이고, 대신 **맵 구조·이동·사격 규칙을 발로란트 수치에 맞췄어요.**
맵이 눈에 익은 상태에서 연습해야 인게임에서도 그 에임이 나온다는 생각으로 만들었습니다.

## 바로 하기 (윈도우, 터미널 필요 없음)

1. <https://nodejs.org> 에서 **LTS** 버전을 설치합니다. (한 번만)
2. 이 저장소를 내려받아 압축을 풉니다. (GitHub → 브랜치 고르기 → **Code → Download ZIP**)
3. `valoaim` 폴더 안의 **`start-windows.bat`** 을 더블클릭합니다.
4. 2초 뒤 브라우저가 `http://localhost:3300` 으로 열립니다. 연습하는 동안 **검은 창을 닫지 마세요.**

처음 한 번만 파일을 받느라 조금 걸리고, 그다음부터는 바로 켜집니다.
크롬 또는 엣지 권장 (마우스 원시 입력 지원). 화면의 **연습 시작**을 누르면 전체화면 + 마우스 잠금이 됩니다.

터미널로 할 때는:

```bash
cd valoaim
npm install
npm start          # http://localhost:3300
```

### 내 감도 (기본값)

- DPI **800**, 감도 **0.4** → 360° = **40.8cm** (16.1인치), eDPI 320
- 발로란트와 같은 공식: 마우스 1카운트당 `0.07° × 감도`, 시야각 가로 **103°** 고정
- 조준(우클릭) 감도는 발로의 '조준 감도 배율'(기본 1.0)과 같게 계산합니다 (줌 1.25배만큼 느려짐)
- 게임 중 `F2` → 마우스를 40.8cm 움직이면 정확히 360° 도는지 확인할 수 있어요
- 설정의 **원시 입력**을 켜 두면 윈도우 마우스 가속·포인터 속도가 무시됩니다 (발로 '원시 입력 버퍼'와 같은 효과, 크롬·엣지).
  파이어폭스는 원시 입력을 지원하지 않아서 윈도우 포인터 속도 6/11, '포인터 정확도 향상' 끔이어야 발로와 같아요.

## 연습 모드

| 모드 | 내용 |
| --- | --- |
| 데스매치 | 바인드 곳곳(사이트·후카·램프·가든·헤븐…)에 봇 1~16명. 돌아다니며 각을 잡고, 죽으면 내가 안 보는 곳에서 다시 나옴 |
| 각 잡기 | 실제 자리에서 각 보기 — A 트럭→램프, 헤븐→샤워 출구, A 숏 진입, B 사이트→후카 창문, 엘보→가든, B 롱→가든 끝. 봇이 와이드/어깨/지글 피킹 |
| 1:1 스트레이프 | 봇 하나가 AD 무빙(발로와 같은 가감속). 카운터 스트레이핑 → 멈춰서 쏘기 연습 |
| 맵 둘러보기 | 봇 없이 맵 익히기. `B` 로 보는 곳에 봇 놓기 |

봇 반격(끔/쉬움/보통/어려움)을 켜면 봇이 반응 시간 뒤에 멈춰서 쏩니다.
`Tab` 을 누르고 있으면 기록: 명중률, 헤드샷 비율, **첫 발 헤드샷**, **멈춰서 쏜 비율**, 보이고→킬 시간, 첫 명중→킬 시간.

## 들어간 발로란트 규칙

[확인] = 공개된 수치, [추정] = 인게임 감각·측정에 맞춘 근사값. 전부 `public/js/sim/valorant.js` 한 파일에 있어서 숫자만 고치면 됩니다.

**밴달**
- 연사 9.75발/초, 조준 시 0.9배(8.775발/초) [확인]
- 데미지 머리 160 / 몸 40 / 다리 34, 거리 감소 없음 → 헤드 한 방, 몸 4발 (체력 100 + 중방어구 50) [확인]
- 탄창 25 / 예비 50, 재장전 2.5초, 꺼내기 1초, 다 쏘면 자동 재장전 [확인] (예비 탄약 무한은 설정에서 끌 수 있음)
- 첫 발 퍼짐 0.25°, 조준 0.157° [확인] · 조준 1.25배 줌 [확인]
- 스프레이: 처음 몇 발은 거의 직선으로 오르고 10발 근처부터 좌우로 흔들림, 3발째부터 퍼짐 증가 [추정]
- 반동 회복: 끊어 쏘면(탭) 매번 첫 발 정확도로 돌아옴 [추정: 회복 속도]
- 반동 중 화면은 일부만 올라가고(30%) 나머지는 탄이 크로스헤어 위로 튐 → 아래로 당겨서 제어 [추정]
- 앉으면 퍼짐 ×0.85 [추정]

**이동**
- 밴달 들고 달리기 5.4 m/s, 칼 6.75 m/s, 조준 중 4.104 m/s [확인]
- **정확 사격 기준: 최고 속도의 27.5% 이하로 움직이면 이동 오차 0** [확인: 패치 3.0 에서 30%→27.5%]
- 걷기(Shift) 약 55%, 앉아 걷기 45% [추정]
- 키를 놓으면 약 0.1초 안에 멈추고, 반대키(카운터 스트레이핑)를 누르면 조금 더 빨리 섬 — 발로는 CS 보다 차이가 작음 [추정]
- 속도에 따라 이동 오차가 커짐(걷기 2.6°, 달리기 6°), 공중이면 11° [추정]
- 점프 약 1m, 착지 직후 잠깐 느려짐, 계단·턱 자동으로 오름 [추정]
- 발소리: 달리면 나고 걷기·앉기는 안 남. 봇 발소리는 방향·거리감 있게 들림
- 128틱으로 계산 (발로 서버와 같음)

**맵 (바인드)**
- 미드 없음, 단방향 텔레포터 2개: **A 숏 → B 숏(후카 쪽)**, **B 롱(가든 옆) → A 로비(샤워 쪽)**. 들어간 방향 기준으로 시점이 돌아감
- 텔레포터 출구 방 문은 닫혀 있다가 안에서 다가가면 열림
- 후카는 0.9m 높고 창문으로 B 사이트에 뛰어내림, A 헤븐은 3m 위 (계단·난간), A 트럭·트리플 박스, B 사이트 가운데 큰 구조물, 가든 아치
- 화면 왼쪽 위 미니맵(북쪽 위 고정) + 지금 위치 이름, `M` 큰 지도(위치 이름 표시)

**크로스헤어**
- 발로 크로스헤어 **코드를 그대로 붙여넣기** 가능 (설정 → 크로스헤어). 연사 오차·이동 오차 표시도 발로처럼
- 적 하이라이트 빨강/노랑/보라

## 알아둘 점

- **맵은 바인드 구조(위치 관계·동선·이름)를 따라 직접 쌓은 것**이라 실제 인게임과 몇 m 씩 차이가 날 수 있어요.
  `public/js/sim/bind.js` 에 사각형 데이터로 들어 있어서, 어디가 다르다고 알려 주시면(미니맵 캡처가 있으면 더 좋아요) 바로 고칠 수 있어요.
- 벽 관통(월뱅)은 아직 없습니다 — 모든 벽이 총알을 막아요.
- 브라우저 화면 주사율(rAF)에 맞춰 그립니다. 144Hz 모니터면 144FPS까지.
- `Ctrl` + `W` 는 브라우저 탭 닫기라서, 전체화면이 아닐 때는 앉기를 `C` 로 쓰세요. (전체화면에서는 막아 둡니다)

## 인터넷에 올리기 (Render 무료)

저장소 최상위 `render.yaml` 블루프린트에 **`valo-aim`** 서비스로 들어 있어요. 다른 게임과는 서버도 주소도 따로입니다.
이미 블루프린트로 올려 둔 게 있다면 Render 대시보드 → Blueprints → 이 저장소 → **Sync** 하면 추가됩니다.
직접 만들 때는 New + → Web Service → Root Directory `valoaim`, Build `npm ci --omit=dev`, Start `npm start`, Health Check `/healthz`.

## 구조

```
server.js                 정적 파일 + Three.js 제공 (혼자 하는 연습장이라 서버 계산 없음)
public/js/sim/            화면과 상관없는 계산 (node 테스트에서 그대로 돌아감)
  valorant.js             발로란트 수치 전부 (감도 공식, 밴달, 이동, 판정 박스)
  bind.js                 바인드 맵 데이터 (구역 사각형, 계단, 상자, 텔레포터, 연습 자리)
  mapgrid.js              맵 → 0.25m 높이 격자 (충돌·총알·그리기 공용), 총알 광선 판정
  movement.js             가속·감속·카운터 스트레이핑·걷기·앉기·점프·계단
  weapon.js               연사·퍼짐·스프레이·회복·재장전·조준
  bots.js                 봇 판정 박스, 스트레이프·피킹·돌아다니기·반격
  game.js                 모드, 사격 판정, 기록, 텔레포터, 문
  settings.js             설정 저장, 발로 크로스헤어 코드 읽기
public/js/client/         Three.js 화면, HUD, 소리, 메뉴
test/                     수치·맵 연결·판정·서버 테스트 (npm test)
```
