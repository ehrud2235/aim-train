# 발로 에임장 — 바인드

발로란트 **바인드 맵**을 그대로 걸어다니면서 **밴달**로 에임 연습하는 브라우저 연습장입니다.
그래픽은 최소한(면 색 + 1m 타일 무늬)이고, 대신 **맵 구조·이동·사격 규칙을 발로란트 수치에 맞췄어요.**
맵이 눈에 익은 상태에서 연습해야 인게임에서도 그 에임이 나온다는 생각으로 만들었습니다.

### 내 감도 (기본값)

- DPI **800**, 감도 **0.4** → 360° = **40.8cm** (16.1인치), eDPI 320
- 발로란트와 같은 공식: 마우스 1카운트당 `0.07° × 감도`, 시야각 가로 **103°** 고정
- 조준(우클릭) 감도는 발로의 '조준 감도 배율'(기본 1.0)과 같게 계산합니다 (줌 1.25배만큼 느려짐)
- 게임 중 `F2` → 마우스를 40.8cm 움직이면 정확히 360° 도는지 확인할 수 있어요
- 설정의 **원시 입력**을 켜 두면 윈도우 마우스 가속·포인터 속도가 무시됩니다 (발로 '원시 입력 버퍼'와 같은 효과, 크롬·엣지).
  파이어폭스는 원시 입력을 지원하지 않아서 윈도우 포인터 속도 6/11, '포인터 정확도 향상' 끔이어야 발로와 같아요.

## 화면은 발로란트 그대로

- **HUD**: 왼쪽 위 미니맵(발로 미니맵 모양, 회전·고정·크기·확대·시야 표시 설정), 위 가운데 남은 시간 + 내 킬 / 1등 킬,
  오른쪽 위 킬 피드(요원 아이콘 · 밴달 아이콘 · 헤드샷 표시), 아래 방어구·체력 | 스킬(데스매치라 회색) | 탄약, 오른쪽 아래 무기 목록
- 데미지 숫자·히트마커 없음(발로와 같음) — 맞히면 피 튀김 + 헤드샷 소리 + 킬 배너 + 킬 소리로 확인
- 맞으면 가운데 둘레에 **맞은 방향 빨간 호**, 체력 30 이하면 체력 숫자가 빨갛게 깜빡임
- 죽으면 **처치한 적 · 받은 피해 / 준 피해**(전투 보고) + 1.5초 부활 막대
- `Tab` 점수판(데스매치 14명 순위 · 처치/사망/지원) + 아래에 내 연습 기록, `Caps Lock`(또는 `M`) 큰 지도(위치 이름)
- 설정(`Esc`)도 발로 설정 화면처럼: **연습 · 일반 · 조작키 · 조준선 · 비디오 · 오디오** 탭
- 폰트는 발로 글꼴(DIN Next / Tungsten)과 비슷한 무료 글꼴 Barlow / Barlow Condensed
- **HUD 위치 맞추기**: 설정 → 연습 → '맞추기 시작'. 내 발로 스크린샷(1920×1080)을 반투명하게 겹쳐 놓고 HUD 요소를 끌어서(휠 = 크기) 똑같은 자리에 맞출 수 있어요

## 연습 모드

| 모드 | 내용 |
| --- | --- |
| 데스매치 | **발로 데스매치 규칙 그대로**: 적 13명(나 포함 14명), 먼저 40킬 또는 9:00, 죽으면 1.5초 뒤 적에게서 먼 곳에 부활(부활하면 적 위치가 잠깐 미니맵에), 움직이거나 쏘기 전까지 무적, 킬하면 탄창 가득, 죽은 자리에 10초짜리 회복팩. 규칙을 '끝없이'로 바꿀 수도 있어요 |
| 각 잡기 | 실제 자리에서 각 보기 — 적이 실제 엄폐물 모서리에서 피킹 |
| 1:1 스트레이프 | 적 하나가 AD 무빙. 카운터 스트레이핑 → 멈춰서 쏘기 연습 |
| 맵 둘러보기 | 적 없이 맵 익히기. `B` 로 보는 곳에 적 놓기 |

연습장(The Range) 옵션처럼 **적 반격(끔/쉬움/보통/어려움), 적 방어구, 무한 탄약**을 고를 수 있어요.
발로에 없는 연습 도움(속도계, 실제 퍼짐 원, 데미지 숫자, 지금 위치 이름)은 기본으로 꺼져 있고 설정 → 연습에서 켤 수 있어요.

## 들어간 발로란트 규칙

[확인] = 공개된 수치(패치 노트·게임 데이터), [추정] = 라이엇이 공개하지 않아 측정·근사한 값. 전부 `js/sim/valorant.js` 한 파일에 있어서 숫자만 고치면 됩니다.

**밴달**
- 연사 9.75발/초, 조준 시 8.775발/초 [확인] · 탄창 25 / 예비 50, 재장전 2.5초, 꺼내기 1초 [확인]
- 데미지 머리 160 / 몸 40 / 다리 34, 거리 감소 없음 [확인]
- 방어구 50 은 **맞을 때마다 피해의 66% 를 대신 받음** [확인: 패치 9.10] → 헤드 한 방, 몸 4발, 다리 5발
- 사격 오차: 첫 발 0.25°(조준 0.1575°) → 연사하면 최대 1.0°(조준 1.02°), 앉으면 ×0.85 [확인]
- 이동 오차: 걷기 +3°, 달리기 +6°, 공중 +10°, 앉아 이동 +0.8° [확인: 패치 9.10], 착지 직후 0.225초 +7° [확인: 패치 1.09]
- 스프레이: **1~6발은 위로만**, 그 뒤 좌우로 흔들림(발마다 10% 확률로 방향 전환, 한쪽 끝→반대쪽 0.6초) [확인: 패치 11.08] · 크기(8발째 약 7.85°, 최대 약 9°) [추정: 영상 측정]
- 반동 회복 0.375초, 회복 중에 끊어 쏘면 1/6 발만 쌓임(Tap Efficiency 6) [확인: 패치 0.50]
- 화면은 지향사격 때 반동의 약 50%, 조준하면 100% 를 따라감 [추정 / 확인] · 달리며 쏘면 세로 반동 ×1.8 [확인: 패치 6.11]
- 조준 1.25배 줌 = 가로 시야 103 / 1.25 = 82.4° [추정: FOV 계산기]

**이동**
- 밴달 들고 달리기 5.4 m/s, 칼 6.75 m/s, 조준 중 4.104 m/s [확인]
- **정확 사격 기준: 최고 속도의 27.5% 이하** [확인: 패치 3.0]
- 키를 놓으면 걷기 속도까지 약 0.075초, 정확 사격 속도까지 약 0.16초. 반대키(카운터 스트레이핑)는 약 10ms 만 빠름 [확인: 라이엇 개발자 수치]
- **태깅**: 맞으면 72.5% 느려졌다가 돌아옴 [확인: 패치 3.0] — 맞힌 적도, 맞은 나도
- 걷기(Shift) 약 55%, 앉아 걷기 45%, 점프 약 0.9m [추정]
- 발소리: 달리면 나고 걷기·앉기는 안 남. 적 발소리·총소리는 방향·거리감 있게 들림
- 128틱으로 계산 (발로 서버와 같음)

**맵 (바인드)** — 실제 게임 데이터(공개된 내비메시·시야 데이터)를 변환한 진짜 바인드 구조
- 단방향 텔레포터 2개 (A 숏 → B 출구, B 텔레포터 → A 출구), 들어간 방향 기준으로 시점 유지
- 높이: A 사이트 1m, A 숏·램프 2m, A 타워(헤븐) 4m, 후카 5m, B 사이트 3.6m

**크로스헤어**
- 발로 크로스헤어 **코드를 그대로 붙여넣기** 가능 (설정 → 조준선). 사격 오차·이동 오차 표시와 배율, '사격 오차에 따라 조준선 흐리게'까지
- 적 강조 색상 4가지(빨강 / 보라 / 노랑 2종)

## 알아둘 점

- 벽 관통(월뱅)은 아직 없습니다 — 모든 벽이 총알을 막아요. 낙하 데미지는 바인드에서 생길 높이가 없어서 넣지 않았어요.
- 건물 지붕·실내 천장·텔레포터 출구 문은 아직 없고, 벽 높이는 일정해요 (지형 데이터에 없는 부분).
- 브라우저 화면 주사율(rAF)에 맞춰 그립니다. 144Hz 모니터면 144FPS까지.
- `Ctrl` + `W` 는 브라우저 탭 닫기라서, 전체화면이 아닐 때는 앉기를 `C` 로 쓰세요. (전체화면에서는 막아 둡니다)
